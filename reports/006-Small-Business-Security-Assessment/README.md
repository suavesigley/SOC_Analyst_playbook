# 006 – Small Business Security Assessment

## Overview

This project documents a simulated security posture assessment conducted for a fictional Australian accounting firm.

The assessment was performed as a portfolio project to demonstrate practical cybersecurity assessment, documentation and risk analysis skills expected of a Junior SOC Analyst or Junior Cyber Security Consultant.

The engagement focuses on evaluating an organisation's current security posture through interviews, documentation review and configuration analysis.

No penetration testing or exploitation activities were performed.

---

# Objectives

- Assess current cybersecurity posture
- Identify security weaknesses
- Evaluate Microsoft 365 security
- Review endpoint security controls
- Assess backup and recovery capabilities
- Review identity and access management
- Provide prioritised remediation recommendations

# Key Findings

- MFA not consistently enforced
- Privileged access requires improvement
- Backup resilience requires validation
- Microsoft 365 backup strategy requires review
- Endpoint monitoring is limited
- Security awareness training requires improvement
- USB usage is unrestricted
- BitLocker deployment is inconsistent
