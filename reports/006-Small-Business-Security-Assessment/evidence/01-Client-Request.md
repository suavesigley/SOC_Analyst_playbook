# Client Request

**Client:** BlueWave Accounting Pty Ltd

**Industry:** Accounting & Financial Services

**Employees:** 15

**Assessment Requested By:** Sarah Williams – Office Manager

**Assessment Date:** 7 August 2026

---

## Background

BlueWave Accounting Pty Ltd has recently migrated to Microsoft 365 and implemented Microsoft Intune for device management.

Management has requested an independent review of the organisation's current cybersecurity posture to identify potential weaknesses and prioritise future security improvements.

The organisation has not previously completed a formal security assessment.

---

## Objectives

The client requested an assessment of:

- Identity and Access Management
- Microsoft 365 Security
- Endpoint Security
- Backup & Recovery
- Security Monitoring
- User Security Awareness
- Network Security

---

## Deliverables

The client requested:

- Executive Summary
- Risk Assessment
- Security Findings
- Prioritised Recommendations
- 30/60/90 Day Improvement Roadmap

---

## Scope

### Included

- Microsoft 365
- Windows Endpoints
- Windows Server
- Microsoft Intune
- Microsoft Defender Antivirus
- Backup Configuration
- Corporate Network

### Excluded

- Penetration Testing
- Social Engineering
- Physical Security Testing
- Vulnerability Exploitation

---

## Expected Outcome

Provide practical recommendations suitable for a small business with limited internal IT resources while improving the organisation's overall cyber resilience.
